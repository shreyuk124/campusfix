# CampusFix

A campus issue reporting and resolution platform.

## Problem Statement
CampusFix helps students report problems around their institute and enables college authorities to track, assign, and resolve them.

## Planned Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB Atlas with Mongoose

## Planned Features
- Report and track campus issues
- View existing reports and similar issues
- Assign issues to responsible teams
- Track status from reporting to resolution
- Admin dashboard and issue analytics

## Project Status
Initial setup and planning.
